IPL Data Analytics Dashboard (2008 - 2026)
​📌 Project Overview
​Ye project IPL (Indian Premier League) ke 18+ saal ke data ka ek comprehensive analysis hai. Is dashboard ko banane ka maqsad cricket data se hidden patterns, team consistency, aur player performance trends ko extract karna hai.
​📊 Key Features
​Dynamic Season Filtering: 2008 se 2026 tak kisi bhi season ka data 1-click mein access kiya ja sakta hai.
​Toss Impact Analysis: Ek special KPI jo dikhata hai ki toss jeetne ka match outcome par kitna % asar pada.
​Top Performer Tracking: Orange Cap aur Purple Cap holders ki dynamic images aur unke detailed stats (Strike Rate, Economy, etc.).
​Interactive Points Table: Har season ki team standings, wins, losses aur net run rate ka visual breakdown.
​Venue Insights: Matches kitne alag-alag venues par khele gaye unka total count.
​🛠️ Tech Stack Used
​Power BI: Data Visualization aur Dashboard designing ke liye.
​Power Query: Data cleaning aur transformation (ETL) ke liye.
​DAX (Data Analysis Expressions): Complex measures jaise Strike Rate, Toss Win %, aur Dynamic Titles ke liye.
​MS Excel: Initial data storage aur manual cleaning ke liye.
​📈 Key Insights from Data
​Toss Correlation: Kuch seasons mein toss jeetne ka impact 57% se upar raha, jo matches ki strategy ko define karta hai.
​Consistency: Top teams (CSK, MI) ki consistency points table mein saaf nazar aati hai across multiple seasons.
​Evolution of Scoring: Dashboard se saaf dikhta hai ki kaise 'Total Sixes' ka count early seasons ke muqable badhta gaya hai.
​🚀 How to View
​Is repository se .pbix file download karein.
​Power BI Desktop mein file ko open karein.
​Top-right corner mein diye gaye "Season" slicer ka use karke dashboard explore karein.
